# StreamQ (Live CS AI Assistant)

실시간 스트리밍 답변을 제공하는 고객 지원(CS) AI 어시스턴트 API 서버입니다.

## 🎯 프로젝트 목표
단순한 API 기능 구현을 넘어, **실무 수준의 DB/API 설계(구현력)**와 **WebFlux 및 OS 레벨의 비동기 메커니즘(심층 이론)**을 동시에 마스터하는 것을 목표로 합니다.

## 📁 문서 구조 (Docs)
프로젝트의 세부 설계 근거와 심층 학습 기록은 `docs` 폴더에 분리되어 있습니다.
- [1. 아키텍처 및 구현 설계 (IMPLEMENTATION_DESIGN)](docs/1_IMPLEMENTATION_DESIGN.md)
- [2. OS 레벨 딥다이브: Event Loop와 Context Switching (DEEP_DIVE)](docs/2_DEEP_DIVE.md)

## 🛠 기술 스택
- Kotlin, Spring Boot (WebFlux, Data JPA)
- PostgreSQL (예정)
- Server-Sent Events (SSE) 기반 실시간 스트리밍
