# AI 챗봇 서비스 요구사항 (VIP onboarding 팀 사전과제)

## 1. 개요
* **목표**: 잠재 고객사 대상 AI 챗봇 시연용 API 개발 (향후 확장성 고려)
* **제한 시간**: 3시간 (문서 작업 포함)
* **필수 스택**: Kotlin, Spring Boot
* **선택 스택**: PostgreSQL, H2

## 2. 평가 기준
* 과제를 어떻게 분석 하셨나요?
* 과제 진행에 있어 AI를 어떻게 활용 하셨나요? 어떤 어려움이 있었나요?
* 지원자가 구현하기 가장 어려웠던 1개 이상의 기능을 설명 해주세요.
* (구현의 양은 배점이 낮음)

## 3. 기능 요구사항

### 3.1. 사용자 관리 및 인증 기능
* **사용자(user) 요소**: 이메일(string), 패스워드(string), 이름(string), 생성일시(timestampz), 권한(string: member, admin)
* **기능**:
  * 회원가입 (필수: 이메일, 패스워드, 이름)
  * 로그인 (필수: 이메일, 패스워드) -> JWT 토큰 발급
  * 인증: 회원가입/로그인 제외 모든 API는 JWT 검증

### 3.2. 대화(chat) 관리 기능
* **대화(chat) 요소**: 질문(string), 답변(string), 생성일시(timestampz), 스레드(thread)
* **스레드(thread)**: OpenAI 요청 시 이전 대화 컨텍스트. (유저마다 여러 개 생성 가능, N:1)
  * 생성 조건: 첫 질문이거나, 마지막 질문 후 30분 초과 시 새 스레드 생성. 30분 이내면 유지.
* **기능**:
  * 대화 생성 (파라미터 옵션: `isStreaming`(boolean), `model`(string))
  * 대화 목록 조회 (스레드 단위 그룹화 응답, 본인 것만 조회, 관리자는 전체 조회, 생성일시 오름차순/내림차순 정렬 및 페이지네이션)
  * 스레드 삭제 (본인 스레드만 삭제 가능)

### 3.3. 사용자 피드백 관리 기능
* **피드백(feedback) 요소**: 사용자 ID(string), 대화 ID(string), 긍정/부정 유무(boolean), 생성일시(timestampz), 상태(string: pending, resolved)
* **기능**:
  * 피드백 생성 (자신의 대화에만 생성 가능, 관리자는 모든 대화에 생성 가능. 1개 대화에 1개 유저당 1개 피드백만 가능)
  * 피드백 목록 조회 (본인 것만, 관리자는 전체. 생성일시 정렬, 페이지네이션, 긍정/부정 필터링)
  * 피드백 상태 변경 (관리자 전용, pending/resolved 업데이트)

### 3.4. 분석 및 보고 기능 (관리자 전용)
* **기능**:
  * 사용자 활동 기록 요청: 최근 하루 동안의 회원가입, 로그인, 대화 생성 수 응답.
  * 보고서 생성 요청: 최근 하루 동안의 모든 사용자의 대화 목록 및 생성자 정보 포함하여 CSV 형태로 응답.

### 3.5. OpenAI Chat Completions API 스펙 참조 (제공된 이미지 기반)
* **Endpoint / Action**: Chat Completions API (`openai.chat.completions.create`)
* **목적**: 단일 턴(Single-turn) 및 멀티 턴(Multi-turn) 대화 생성
* **요청 파라미터 구조**:
  * `model` (String): 사용할 모델명 (예: `"gpt-3.5-turbo"`)
  * `messages` (Array): 이전 대화 기록(스레드)을 포함한 메시지 배열. 각 메시지는 다음 요소를 포함:
    * `role` (String): `"system"`, `"user"`, `"assistant"` 중 하나
    * `content` (String): 실제 대화 내용
* **활용 방안**: 대화(chat) 생성 시 스레드에 속한 이전 질문(`"user"`)과 답변(`"assistant"`)을 순서대로 `messages` 배열에 담아 OpenAI에 전송해야 합니다.
